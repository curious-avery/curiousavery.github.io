# Avery H. Liu — GitHub Pages build

This folder is the ready-to-upload static build for:

`https://curiousavery.github.io/`

## Deploy

1. Open the `curiousavery/curiousavery.github.io` repository on GitHub.
2. Upload **the contents of this folder**, not the enclosing folder or ZIP.
3. Confirm `index.html` appears at the repository root.
4. In **Settings → Pages**, choose **Deploy from a branch**, the repository's
   publishing branch (normally `main`), and `/(root)`.
5. Save and allow up to 10 minutes for the deployment.

This is a dependency-free static site. It was exported from the current hosted
Sites source at commit `34c92af4e3fbbb2aeda473fe12ebdc17de1b65d2` and uses
root-relative deployment base `/` through relative asset URLs.
